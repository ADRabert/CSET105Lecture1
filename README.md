# CSET 105 Lecture 1: Types & Operators

## Lecture Info
This lecture introduces the class to JavaScript.

## Features
- Printing a variation of the classic "Hello World"
- Demonstration of numbers & booleans within strings using template literals
- Proper string formatting & escape sequences
- Showcasing how JS automatically does type conversion, & how to override it

## Exercises
1. Output a complexly formatted string in a single console log statement
2. Print the results of mathematical expressions without literally typing the answer
3. Predict the output of various comparisons based on experience
